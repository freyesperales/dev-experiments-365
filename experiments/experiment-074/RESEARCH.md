# Research — Experiment 074 (2026-10-15)

Six parallel scouts (tech trends, SMB pain, devtools, docs/accessibility, practical AI tooling, wildcard). Evidence quality was uneven: news.ycombinator.com was unreachable from the scouts' fetch tool and most search results were undated blogs, so demand claims below are *directional*, not proven.

## Winner: HexLens
- Source: Ask HN "What developer tool do you wish existed in 2026?" (Dec 2025) — https://news.ycombinator.com/item?id=46345827 — snippet asks for an "explorative hex editor where you can do fuzzy searches".
- Gap: ImHex / 010 Editor / Kaitai need a grammar or pattern first (010 is paid); online hex viewers only do exact-byte search.
- Why it won the judge step: only candidate with a directly cited ask, a form factor unlike the last ~10 entries (not an auditor, not a document converter), instantly visible in one screenshot, and repeat use (every unknown file).
