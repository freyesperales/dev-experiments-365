Vigía

Paste your WordPress plugin list. See which plugins, themes and core version are vulnerable, closed on wordpress.org, actively exploited or abandoned, and what to do about each one.

How to get the list (1 minute)
  1. In WordPress: Tools → Site Health → Info → “Copy site info to clipboard”, then paste it below.
  2. Or, if you use WP-CLI: wp core version; wp plugin list; echo themes:; wp theme list
  3. Or type lines like wordpress 6.8.2, contact-form-7 5.9.3, theme astra 4.6.1.

Private by design: your browser only sends plugin and theme names (slugs) and the core version to api.wordpress.org and wpvulnerability.net. Your domain, your plugin versions and the rest of the Site Health text never leave this page.

Data: wordpress.org (latest version, closed plugins, insecure core releases), WPVulnerability (known vulnerabilities, free open API) and the CISA KEV catalog (snapshot ). A clean result means “nothing known”, not “safe”.
