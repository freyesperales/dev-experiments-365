Gatehouse

Paste a GitHub Actions workflow (.github/workflows/*.yml) and see risky patterns: pwn requests, script injection, unpinned actions, broad permissions. Runs entirely in your browser; nothing is uploaded.

En español: pega un workflow de GitHub Actions y revisa patrones riesgosos. Todo ocurre en tu navegador; no se sube nada.

Line-oriented heuristic scanner, not a full YAML parser. A clean result does not prove a workflow is safe.
