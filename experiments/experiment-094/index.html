Leashcheck

Paste the AI-agent config files from a repo (MCP servers, Claude Code settings, rules files) and see risky settings. Runs entirely in your browser; nothing is uploaded. En español: pega los archivos de configuración de agentes de IA de tu repo y revisa riesgos; todo ocurre en tu navegador, nada se sube.

Static, heuristic checks. A clean result does not mean a repo is safe to run an agent in. Filename decides how a file is checked (e.g. .mcp.json, .claude/settings.json, AGENTS.md).
